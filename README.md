# Воскресные речи — PWA

Локальное приложение для планирования приглашений докладчиков. Интерфейс на русском языке.

## Возможности
- Календарь по месяцам, отображающий только воскресенья.
- Добавление и редактирование номера речи, песни, докладчика, контактов, статуса и комментария.
- История по номеру речи: даты предыдущих назначений и предупреждение о повторе.
- Статусы: не связывались, приглашён, ожидает ответа, подтвердил, отказался.
- Локальное сохранение в `localStorage`, экспорт и импорт JSON-резервной копии.
- PWA-кэширование оболочки для офлайн-работы после первого открытия.

## Запуск
Для проверки можно открыть `index.html`, но для установки PWA и работы Service Worker требуется HTTPS или localhost. Разместите содержимое папки на GitHub Pages или другом статическом HTTPS-хостинге, откройте сайт на iPhone в Safari и выберите **Поделиться → На экран «Домой»**.

## Важно
- Данные хранятся только в локальном хранилище браузера на этом устройстве. Очистка данных Safari/браузера может удалить их — регулярно используйте «Экспорт».
- Первое открытие требует интернета для загрузки страницы. После успешного кэширования интерфейс работает офлайн.
- Шрифты Google используются как необязательное улучшение; если они недоступны, приложение использует системный шрифт.
- Приложение не синхронизирует записи между устройствами.

## Импортированная история
При первом запуске в пустое хранилище автоматически добавляется переданный список встреч и речей. Если приложение уже запускалось до обновления, существующие данные не перезаписываются; используйте импорт резервной копии либо очистите данные приложения только после экспорта, чтобы загрузить встроенную начальную историю.

Значения с 🎧 сохранены в комментариях, потому что исходный список не поясняет однозначно, что означает этот значок. Записи без номера речи сохранены как события (конгресс, спецречь, Вечеря и посещение). Данные датированы 2024 и 2026 годами согласно явно указанному году «Январь 26» и последовательности воскресений.

Отдельный файл `historical-data.json` содержит 46 импортированных записей. Его можно выбрать через кнопку «Импорт» в приложении, если нужно загрузить историю в уже установленную версию; импорт заменяет текущие записи, поэтому сначала сделайте экспорт.

## Навигация v5
- Главный экран начинается с текущего месяца и показывает только воскресенья. Проведите пальцем вверх, чтобы перейти к следующему месяцу; стрелок переключения нет.
- Вкладка «История речей» показывает все записи списком с прокруткой; поле поиска фильтрует по номеру речи, докладчику, песне и комментарию.
